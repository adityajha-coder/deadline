# Deadlines

A Chrome extension for tracking deadlines with gentle notification reminders and a calendar view.

---

## Add to Your Browser

Follow these steps to run and install Deadlines in Google Chrome, Brave, Edge, or any Chromium browser:

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/deadlines.git
```

### 2. Navigate into the project folder
```bash
cd deadlines
```

### 3. Install dependencies
```bash
npm install
```

### 4. Build the extension
```bash
npm run build
```
This compiles the extension into the production-ready `dist/` directory.

---

### 5. Load the extension in Chrome

1. Open your browser and navigate to:
   ```text
   chrome://extensions
   ```
2. Turn on **Developer mode** using the toggle switch in the top-right corner.
3. Click the **Load unpacked** button in the top-left corner.
4. Select the **`dist`** folder inside your `deadlines` directory.
5. Click the **puzzle piece icon** in the Chrome toolbar and pin **Deadlines** for quick access.
